# Customer Shopping Behavior Analysis

## Overview

This project analyzes customer shopping behavior using transactional data from 3,900 purchases across different product categories. The analysis focuses on spending patterns, product preferences, customer segments, and subscription behavior to generate useful business insights.

## Tools Used

- Python
- PostgreSQL
- SQL
- Power BI
- Excel

## Project Workflow

- Cleaned and prepared the data using Python
- Performed exploratory data analysis
- Conducted business analysis using PostgreSQL and SQL
- Built an interactive Power BI dashboard
- Generated business insights and recommendations

## SQL Analysis

The analysis covered:
- Revenue by gender
- High-spending discount users
- Top-rated products
- Shipping method comparison
- Subscriber vs. non-subscriber spending
- Discount usage by product
- Customer segmentation
- Top products by category
- Repeat buyers and subscription behavior
- Revenue by age group
